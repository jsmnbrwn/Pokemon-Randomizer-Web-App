A locally hosted web game where a random Pokémon is chosen and you have to work out which one it is. Spend points to reveal clues, then make your guess.

### How to play

Start a new round and a random Pokémon is picked in secret.
Spend points to reveal hints about it. Cheaper hints give less away.
Guess the Pokémon when you think you know it.

---

### Requirements
Node.js (includes npm)#


```bash
git clone https://github.com/YOUR-USERNAME/REPO-NAME.git
cd REPO-NAME

```
